# EquipRent: Advanced Database Dictionary & System Catalog
**Course:** Advanced Database Systems  
**Domain:** Logistics, Fleet & Heavy Equipment Resource Management  
**Target Engine:** PostgreSQL 15+ (Supabase Cloud Database Cluster)  
**Standard:** Third Normal Form (3NF) Strict Relational Architecture  

---

## 1. Relational Entity Overview

The database design consists of **11 distinct, fully normalized operational entities and junction tables**, completely eliminating data anomalies and avoiding null-heavy schemas.

| Table Name | Entity Type | Normalization | Primary Key | Description |
| :--- | :--- | :--- | :--- | :--- |
| `user_profiles` | Strong Entity | 3NF | `id` (UUID) | Decoupled identity profiles separating credentials from operational roles (`admin`, `staff`, `customer`). |
| `warehouse_locations` | Strong Entity | 3NF | `id` (UUID) | Physical logistics depots housing machinery inventory. |
| `equipment_categories` | Classification | 3NF | `id` (UUID) | Machinery categories, base insurance rates, and certification requirements. |
| `equipment` | Strong Entity | 3NF | `id` (UUID) | Physical assets with serial numbers, operational hours, and current status. |
| `rental_orders` | Transaction Header | 3NF | `id` (UUID) | Parent rental contract with dates, delivery location, and financial totals. |
| `rental_order_items` | **Junction Table 1 (N:M)** | 3NF | `id` (UUID) | Many-to-Many resolver linking orders to equipment with dispatch/return telemetry. |
| `payment_transactions` | Audit Transaction | 3NF | `id` (UUID) | Immutable financial transaction audit log for payments and deposits. |
| `maintenance_records` | Entity / Header | 3NF | `id` (UUID) | Work orders for routine servicing and post-rental emergency repairs. |
| `maintenance_tasks` | **Junction Table 2 (N:M)** | 3NF | `id` (UUID) | Many-to-Many resolver linking maintenance work orders to technician labor hours. |
| `equipment_inspections`| Multi-Attribute Audit | 3NF | `id` (UUID) | Check-in/check-out telemetry: fuel levels, structural rating, damage penalties. |
| `audit_logs` | Security Engine Entity| 3NF | `id` (UUID) | Engine-level audit trail storing JSON diffs generated by PostgreSQL triggers. |

## 2. Detailed Data Dictionary Catalogs

### Table 1: `user_profiles`
Separates authentication credentials from system operational profile data (prevents 2NF/3NF partial dependencies).
- **`id`** (`UUID`, Primary Key, `DEFAULT gen_random_uuid()`): Unique identifier.
- **`auth_user_id`** (`UUID`, Nullable, Unique): Foreign key reference to `auth.users(id)` in Supabase Auth.
- **`full_name`** (`VARCHAR(120)`, NOT NULL): Legal name of user.
- **`email`** (`VARCHAR(255)`, NOT NULL, Unique): Email address.
- **`phone`** (`VARCHAR(30)`, NOT NULL): Contact phone number.
- **`company_name`** (`VARCHAR(150)`, Nullable): Registered company/contractor name.
- **`role`** (`user_role_type`, NOT NULL, `DEFAULT 'customer'`): Restricted ENUM (`'admin'`, `'staff'`, `'customer'`).
- **`account_status`** (`VARCHAR(20)`, NOT NULL, `CHECK (account_status IN ('active', 'suspended', 'pending'))`).
- **`created_at`** (`TIMESTAMPTZ`, `DEFAULT NOW()`): Record creation timestamp.
- **`updated_at`** (`TIMESTAMPTZ`, `DEFAULT NOW()`): Managed by trigger `trg_user_profiles_updated_at`.

### Table 2: `warehouse_locations`
- **`id`** (`UUID`, Primary Key): Depot identifier.
- **`branch_code`** (`VARCHAR(15)`, NOT NULL, Unique): Standard business code (e.g., `DEP-METRO-01`).
- **`branch_name`** (`VARCHAR(100)`, NOT NULL): Facility name.
- **`address`** (`TEXT`, NOT NULL): Street address.
- **`city`** (`VARCHAR(80)`, NOT NULL): City.
- **`region`** (`VARCHAR(80)`, NOT NULL): State / Region.
- **`contact_phone`** (`VARCHAR(30)`, NOT NULL): Depot phone.
- **`manager_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE SET NULL`).
- **`max_storage_capacity`** (`INT`, NOT NULL, `CHECK (max_storage_capacity > 0)`).

### Table 3: `equipment_categories`
- **`id`** (`UUID`, Primary Key): Category identifier.
- **`category_name`** (`VARCHAR(80)`, NOT NULL, Unique): Display name (e.g., Heavy Machinery, Earthmoving).
- **`category_code`** (`VARCHAR(20)`, NOT NULL, Unique): Short identifier code.
- **`description`** (`TEXT`): Scope of machinery included.
- **`base_daily_insurance_rate`** (`NUMERIC(10,2)`, `DEFAULT 25.00`, `CHECK (base_daily_insurance_rate >= 0)`).
- **`requires_operator_certification`** (`BOOLEAN`, `DEFAULT FALSE`): Safety compliance flag.

### Table 4: `equipment`
Physical fleet inventory.
- **`id`** (`UUID`, Primary Key): Equipment unit identifier.
- **`serial_number`** (`VARCHAR(60)`, NOT NULL, Unique): Manufacturer VIN / Serial.
- **`model_name`** (`VARCHAR(120)`, NOT NULL): Commercial model name.
- **`manufacturer`** (`VARCHAR(80)`, NOT NULL): Maker (e.g., Caterpillar, Komatsu, Takeuchi).
- **`model_year`** (`INT`, NOT NULL, `CHECK (model_year >= 1990 AND model_year <= 2030)`).
- **`category_id`** (`UUID`, Foreign Key -> `equipment_categories(id) ON DELETE RESTRICT`): Category.
- **`warehouse_id`** (`UUID`, Foreign Key -> `warehouse_locations(id) ON DELETE RESTRICT`): Current depot.
- **`daily_rental_rate`** (`NUMERIC(10,2)`, NOT NULL, `CHECK (daily_rental_rate > 0)`).
- **`replacement_value`** (`NUMERIC(12,2)`, NOT NULL, `CHECK (replacement_value > 0)`).
- **`operational_hours`** (`NUMERIC(10,2)`, `DEFAULT 0.00`, `CHECK (operational_hours >= 0)`).
- **`current_status`** (`equipment_status_type`, `DEFAULT 'available'`): ENUM (`available`, `rented`, `under_maintenance`, `decommissioned`).
- **`image_url`** (`TEXT`): Asset image link.
- **`maintenance_interval_hours`** (`NUMERIC(10,2)`, `DEFAULT 250.00`, `CHECK (maintenance_interval_hours > 0)`).
- **`created_at`** / **`updated_at`**: Managed timestamps.

### Table 5: `rental_orders`
Transaction parent header.
- **`id`** (`UUID`, Primary Key): Order identifier.
- **`order_number`** (`VARCHAR(30)`, NOT NULL, Unique): Human-readable tracking number.
- **`customer_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE RESTRICT`).
- **`authorized_staff_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE SET NULL`).
- **`status`** (`rental_order_status`, `DEFAULT 'draft'`): ENUM (`draft`, `confirmed`, `in_progress`, `completed`, `cancelled`).
- **`expected_start_date`** (`DATE`, NOT NULL).
- **`expected_end_date`** (`DATE`, NOT NULL).
- **`actual_return_date`** (`DATE`, Nullable).
- **`subtotal_amount`** (`NUMERIC(12,2)`, `DEFAULT 0.00`, auto-computed by trigger `trg_recalc_order_financials`).
- **`tax_amount`** (`NUMERIC(12,2)`, `DEFAULT 0.00`, 8% state rate auto-computed by trigger).
- **`security_deposit_amount`** (`NUMERIC(12,2)`, `DEFAULT 0.00`).
- **`total_amount`** (`NUMERIC(12,2)`, `DEFAULT 0.00`, auto-computed by trigger).
- **`payment_status`** (`payment_status_type`, `DEFAULT 'unpaid'`).
- **`delivery_address`** (`TEXT`).
- **`CONSTRAINT chk_order_date_range CHECK (expected_end_date >= expected_start_date)`**.

### Table 6: `rental_order_items` (Junction Table 1: N:M Orders <-> Equipment)
Resolves many-to-many relationship with rich intersection attributes.
- **`id`** (`UUID`, Primary Key).
- **`rental_order_id`** (`UUID`, Foreign Key -> `rental_orders(id) ON DELETE CASCADE`).
- **`equipment_id`** (`UUID`, Foreign Key -> `equipment(id) ON DELETE RESTRICT`).
- **`unit_daily_rate`** (`NUMERIC(10,2)`, NOT NULL, `CHECK (unit_daily_rate > 0)`).
- **`days_rented`** (`INT`, NOT NULL, `CHECK (days_rented > 0)`).
- **`daily_insurance_rate`** (`NUMERIC(10,2)`, `DEFAULT 0.00`).
- **`item_subtotal`** (`NUMERIC(12,2)`, NOT NULL, `CHECK (item_subtotal >= 0)`).
- **`item_status`** (`item_rental_status`, `DEFAULT 'reserved'`): ENUM (`reserved`, `dispatched`, `returned`, `damaged`).
- **`dispatch_odometer_hours`** (`NUMERIC(10,2)`): Hours reading when leaving depot.
- **`return_odometer_hours`** (`NUMERIC(10,2)`): Hours reading upon return.
- **`dispatched_at`** (`TIMESTAMPTZ`, Nullable).
- **`returned_at`** (`TIMESTAMPTZ`, Nullable).
- **`condition_notes`** (`TEXT`, Nullable).
- **`CONSTRAINT uq_order_equipment UNIQUE (rental_order_id, equipment_id)`**.
- **`CONSTRAINT chk_return_odometer CHECK (return_odometer_hours IS NULL OR return_odometer_hours >= dispatch_odometer_hours)`**.

### Table 7: `payment_transactions`
- **`id`** (`UUID`, Primary Key).
- **`rental_order_id`** (`UUID`, Foreign Key -> `rental_orders(id) ON DELETE RESTRICT`).
- **`transaction_reference`** (`VARCHAR(64)`, NOT NULL, Unique).
- **`payment_method`** (`payment_method_type`): ENUM (`credit_card`, `bank_transfer`, `corporate_credit`, `cash`).
- **`amount`** (`NUMERIC(12,2)`, NOT NULL, `CHECK (amount > 0)`).
- **`transaction_status`** (`VARCHAR(20)`, `CHECK (transaction_status IN ('pending', 'succeeded', 'failed', 'refunded'))`).
- **`processed_at`** (`TIMESTAMPTZ`, `DEFAULT NOW()`).
- **`processed_by`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE SET NULL`).

### Table 8: `maintenance_records`
- **`id`** (`UUID`, Primary Key).
- **`work_order_number`** (`VARCHAR(30)`, NOT NULL, Unique).
- **`equipment_id`** (`UUID`, Foreign Key -> `equipment(id) ON DELETE RESTRICT`).
- **`maintenance_type`** (`maintenance_type_enum`): ENUM (`scheduled_routine`, `emergency_repair`, `post_rental_inspection`, `major_overhaul`).
- **`maintenance_status`** (`maintenance_status_enum`, `DEFAULT 'pending'`): ENUM (`pending`, `in_progress`, `completed`, `cancelled`).
- **`scheduled_date`** (`DATE`, NOT NULL).
- **`completed_date`** (`DATE`, Nullable).
- **`odometer_hours_at_service`** (`NUMERIC(10,2)`, NOT NULL).
- **`parts_cost`** (`NUMERIC(10,2)`, `DEFAULT 0.00`).
- **`labor_cost`** (`NUMERIC(10,2)`, `DEFAULT 0.00`).
- **`total_maintenance_cost`** (`NUMERIC(10,2)`, `DEFAULT 0.00`).
- **`lead_technician_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE SET NULL`).
- **`service_description`** (`TEXT`, NOT NULL).

### Table 9: `maintenance_tasks` (Junction Table 2: N:M Maintenance <-> Technicians)
- **`id`** (`UUID`, Primary Key).
- **`maintenance_id`** (`UUID`, Foreign Key -> `maintenance_records(id) ON DELETE CASCADE`).
- **`technician_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE RESTRICT`).
- **`task_code`** (`VARCHAR(30)`, NOT NULL).
- **`task_name`** (`VARCHAR(120)`, NOT NULL).
- **`hours_logged`** (`NUMERIC(6,2)`, `DEFAULT 0.00`, `CHECK (hours_logged >= 0)`).
- **`hourly_labor_rate`** (`NUMERIC(8,2)`, NOT NULL, `CHECK (hourly_labor_rate > 0)`).
- **`task_cost`** (`NUMERIC(10,2)`, `GENERATED ALWAYS AS (hours_logged * hourly_labor_rate) STORED`).
- **`progress_status`** (`VARCHAR(20)`, `CHECK (progress_status IN ('assigned', 'in_progress', 'completed', 'blocked'))`).
- **`findings_report`** (`TEXT`).
- **`sign_off_timestamp`** (`TIMESTAMPTZ`).

### Table 10: `equipment_inspections`
Check-in and Check-out Telemetry.
- **`id`** (`UUID`, Primary Key).
- **`rental_order_item_id`** (`UUID`, Foreign Key -> `rental_order_items(id) ON DELETE CASCADE`).
- **`inspector_id`** (`UUID`, Foreign Key -> `user_profiles(id) ON DELETE RESTRICT`).
- **`inspection_type`** (`inspection_type_enum`): ENUM (`pre_dispatch`, `post_return`).
- **`fuel_level_percent`** (`INT`, `CHECK (fuel_level_percent BETWEEN 0 AND 100)`).
- **`odometer_reading`** (`NUMERIC(10,2)`, `CHECK (odometer_reading >= 0)`).
- **`cleanliness_rating`** (`INT`, `CHECK (cleanliness_rating BETWEEN 1 AND 5)`).
- **`structural_integrity_rating`** (`INT`, `CHECK (structural_integrity_rating BETWEEN 1 AND 5)`).
- **`damage_identified`** (`BOOLEAN`, `DEFAULT FALSE`).
- **`damage_assessment_notes`** (`TEXT`).
- **`penalty_fee`** (`NUMERIC(10,2)`, `DEFAULT 0.00`, `CHECK (penalty_fee >= 0)`).
- **`sign_off_status`** (`BOOLEAN`, `DEFAULT TRUE`).

### Table 11: `audit_logs` (Universal Database Engine Trigger Log)
- **`id`** (`UUID`, Primary Key).
- **`table_name`** (`VARCHAR(80)`, NOT NULL).
- **`record_id`** (`VARCHAR(64)`, NOT NULL).
- **`action_type`** (`VARCHAR(10)`, `CHECK (action_type IN ('INSERT', 'UPDATE', 'DELETE'))`).
- **`old_data`** (`JSONB`): Snapshot of row before mutation.
- **`new_data`** (`JSONB`): Snapshot of row after mutation.
- **`changed_fields`** (`TEXT[]`).
- **`performed_by`** (`UUID`, Nullable).
- **`executed_at`** (`TIMESTAMPTZ`, `DEFAULT NOW()`).
